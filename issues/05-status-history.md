# 05. История смены статусов: запись и защита от подделки

**Метка:** `security`  
**Статус:** выполнен

Каждая смена статуса сохраняется: кто, когда, из какого статуса в какой, комментарий (если есть).

- [x] Запись истории делает база (в функции смены статуса или триггером на `tasks`), а не клиент
- [x] Запись о создании задачи (— → Новая)
- [x] `changed_by` и `changed_at` берутся из `auth.uid()` и `now()`, подменить их нельзя
- [x] Через API историю нельзя добавить, изменить или удалить (нет политик + отозваны привилегии)

**Готово, когда:** попытка `insert/update/delete` в историю от любого пользователя падает.
